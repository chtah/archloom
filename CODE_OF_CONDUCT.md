# Code of Conduct

Archloom follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to this repository's issues, pull requests and any other project space.

In short: be respectful, assume good faith, keep criticism about the work, and do
not harass or demean anyone.

## Reporting

Archloom has no project email address. To report conduct privately, open
[Security Advisories](https://github.com/chtah/archloom/security/advisories),
choose **Report a vulnerability** and state that the report is about conduct. Only
the maintainer can read it. GitHub's own
[report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
tools are also available.

The maintainer reviews reports and may edit or remove content, or block an
account from the repository. No response time is promised.
